## 📌 Featured Projects

### 🧪 LLM Hallucination Evaluation Framework
Framework for measuring and reducing LLM hallucinations: LLM-as-judge scoring, TruthfulQA integration, multi-model comparison, and Brier score calibration analysis, with a live Streamlit dashboard. Found that cite-or-abstain prompting cut hallucinations by ~55% vs. baseline, while "confident" prompting doubled them.

→ [Repo](https://github.com/loxhness/llm-hallucination-eval) · [Live dashboard](https://uzair-llm-hallucination-framework.streamlit.app)

### 🩺 devpulse-mcp
TypeScript MCP server that gives AI assistants diagnostics on your local dev environment. Published on npm.

→ [npm](https://www.npmjs.com/package/devpulse-mcp)

### 🤖 Enterprise AI Operations Copilot
Multi-agent IT support assistant for a fictional wholesale company, built with LangGraph, FastAPI, Next.js, pgvector, n8n, and LangSmith tracing.

### 🔍 LogLens
High-performance log analysis tool built in Go, using concurrency patterns for real-time processing.

→ [Repo](https://github.com/loxhness/LogLens)

### 🍽 TopDish
Full-stack social food discovery app with real-time updates and scalable architecture.

→ [Live app](https://blue-beach-0dd302e10.2.azurestaticapps.net/)

### 💍 Wedding RSVP Platform
Next.js 15 + Supabase app with family-based login, per-event RSVP tracking, an admin panel, email confirmations, and calendar integration. Deployed on Vercel.
